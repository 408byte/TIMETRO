# 📅 TIMETRO 行事曆助手

TIMETRO 是一個輕量級的「行程與日記管理系統」，結合了行程提醒、拍立得風格日記牆與月度回顧功能。它專為希望高效管理行程並以視覺化方式保存回憶的用戶設計。

## 🌟 系統亮點 (Features)

*   **精準行程管理**：支援日期、時間設置與提醒，並利用 **UUID** 確保每一筆行程的唯一識別與資料完整性。
*   **拍立得式日記牆**：系統可自動將有相片的行程整理成日記牆，並支援匯出成精美圖片。
*   **細粒度圖片管理**：支援單行程內多張相片管理，每張照片皆可獨立編輯說明文字。
*   **自動化提醒服務**：背景監控鬧鐘機制，確保重要行程不遺漏。
*   **資料一致性閉環**：前端採用資料驅動視圖 (Data-Driven View) 設計，確保 UI 畫面與後端 JSON 資料庫即時同步。

## 🛠 技術規格 (Tech Stack)

*   **後端**：Python (Flask), JSON (檔案儲存)
*   **前端**：原生 JavaScript (ES6+), CSS3
*   **核心套件**：
    *   `html2canvas`: 用於日記牆截圖下載。
    *   `uuid`: 用於行程的身分證機制。

## ⚙️ 快速啟動 (Quick Start)

### 環境需求
*   已安裝 Python 3.x
*   已安裝 Flask: `pip install flask`

### 啟動步驟
1.  **下載專案**：將專案檔案解壓縮。
2.  **執行伺服器**：在專案根目錄開啟終端機，執行：
```bash
    python web_service.py
    ```
3.  **進入系統**：開啟瀏覽器，輸入 [http://127.0.0.1:5001](http://127.0.0.1:5001) 即可開始使用。

## 📁 專案架構 (Structure)

*   `web_service.py` : 後端主程式，處理所有 API 請求。
*   `storage.py` : 資料存取層，負責資料的讀寫與持久化。
*   `timetro_data.json` : 資料儲存檔案。
*   `templates/` : 存放核心網頁介面。

---

## 📝 設計理念 (Design Philosophy)

本系統遵循 **「解耦 (Decoupling)」** 與 **「資料驅動 (Data-Driven)」** 原則：
*   **邏輯與視覺分離**：將資料處理引擎與 UI 渲染引擎分開，確保介面更新的高效與穩定。
*   **防禦性編程**：在讀寫檔案與資料載入時皆加入容錯檢查，保證系統在邊緣情況下依然健壯。
